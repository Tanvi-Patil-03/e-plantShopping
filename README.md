# e-plantShopping

## Paradise Nursery Shopping Application

Paradise Nursery is a React-based online plant shopping application that allows users to explore and purchase a variety of indoor plants.

## Features

- Landing page with Get Started button.
- Navigation between Home, Plants and Shopping Cart.
- Plant categories including Air Purifying, Aromatic and Medicinal Plants.
- Product cards with images, descriptions and prices.
- Add plants to the shopping cart.
- Increase and decrease product quantities.
- Delete products from the cart.
- Automatic shopping cart total calculation.
- Continue Shopping and Checkout options.

## Technologies Used

- React.js
- JavaScript
- CSS
- Redux Toolkit
- Vite
